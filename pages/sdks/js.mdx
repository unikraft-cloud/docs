`@unikraft/cloud` is the official JavaScript and TypeScript SDK for the [Unikraft Cloud](https://unikraft.com) API.
The package is fully typed, and it covers the per-metro [platform API](/api/platform/v1) and the global control plane API.

## Installation

```sh
npm install @unikraft/cloud
```

The SDK needs Node.js 22.12 or later, and it ships as ECMAScript modules (ESM) only.
From that version, Node.js can `require()` an ESM package, so CommonJS code can load it too.

## Quickstart

This example creates a client, starts an instance in the `fra` metro, waits until the instance runs, then deletes it.

```ts title="quickstart.ts"
import { UnikraftCloud } from "@unikraft/cloud";

const ukc = new UnikraftCloud({ token: process.env.UKC_TOKEN });
const fra = ukc.metro("fra");

const instance = await fra.instances.create({
  image: "nginx:latest",
  memory_mb: 256,
  autostart: true,
  service_group: {
    services: [{ port: 443, handlers: ["tls", "http"], destination_port: 80 }],
  },
});

await fra.instances.get({ uuid: instance.uuid! }).wait({ state: "running" });
console.log(instance.name, instance.uuid);

await fra.instances.delete([{ uuid: instance.uuid! }]);
```

Three ideas from this example come back on every page of this section:

- `ukc.metro("fra")` limits the client to one [metro](/sdks/js/metros).
  Without a limit, a read covers every metro of the account.
- `fra.instances.get(...)` returns a [handle](/sdks/js/resources#handles).
  A handle sends nothing until you await it, and every operation on it returns a new handle, so `.wait(...)` chains.
- `{ uuid }` is a [ref](/sdks/js/resources#refs).
  A ref is `{ name }` or `{ uuid }`, and it names one resource.

## Authentication

Every request carries a bearer token.
Create the token in the [Unikraft Cloud console](https://console.unikraft.cloud), then pass it to the constructor:

```ts
const ukc = new UnikraftCloud({ token: "..." });
```

Or set the `UKC_TOKEN` environment variable, and create the client with no arguments:

```sh
export UKC_TOKEN=...
```

```ts
const ukc = new UnikraftCloud();
```

## Two layers

The SDK has two layers, and you choose the layer per call.

| Layer         | Import                                                               | What you get                                                                                                        |
| ------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Idiomatic** | `@unikraft/cloud`                                                    | Short verbs such as `ukc.instances.get`, results without the response envelope, automatic pagination, metro fan-out, chainable handles |
| **Raw**       | `@unikraft/cloud/api/platform`, `@unikraft/cloud/api/controlplane`   | One method per `operationId` of the OpenAPI specification, the raw response envelope, one metro per call             |

Use the idiomatic layer by default.
The raw layer is one property away, as `ukc.api`, for every operation that the idiomatic layer doesn't cover yet.
See [the raw API](/sdks/js/resources#the-raw-api).
