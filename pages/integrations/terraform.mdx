The Unikraft Cloud Terraform provider lets you manage unikernel instances,
volumes, and certificates on Unikraft Cloud using Terraform.
It wraps the Go SDK and supports Terraform >= 1.4.

## Installation

Add the provider to your Terraform configuration:

```terraform title="main.tf"
terraform {
  required_providers {
    ukc = {
      source  = "unikraft-cloud/ukc"
      version = "~> 0.5"
    }
  }
}
```

Then run:

```bash title=""
terraform init
```

## Authentication and configuration

The provider applies configuration in the following order:

1. Parameters in the provider configuration block
2. Environment variables

### Environment variables (recommended)

```bash title=""
export UKC_TOKEN='your-api-token'
export UKC_METRO='fra0'
```

```terraform title="main.tf"
provider "ukc" {}
```

### Provider configuration block

:::caution
Hard-coded credentials risk secret leakage if you commit the file to version control.
:::

```terraform title="main.tf"
provider "ukc" {
  metro = "fra0"
  token = "your-api-token"
}
```

### Provider schema

| Argument | Type | Description |
|----------|------|-------------|
| `metro` | String | API metro (e.g. `fra0`). Defaults to `fra0`. |
| `token` | String (sensitive) | API token. |

## Resources

### `ukc_instance`

Creates and manages a Unikraft Cloud instance with an attached service group.

All changes to force-replace attributes destroy and recreate the instance.
In-place updates for instances aren't supported.

#### Example

```terraform title="main.tf"
resource "ukc_instance" "app" {
  image = "nginx:latest"

  service_group = {
    services = [
      {
        port             = 443
        destination_port = 8080
        handlers         = ["tls", "http"]
      }
    ]
    domains = [
      {
        name        = "app.example.com"
        certificate = { name = "my-cert" }
      }
    ]
  }

  memory_mb = 256
  autostart = true
}
```

#### Argument reference

| Argument | Required | Force-replace | Description |
|---|---|---|---|
| `image` | Yes | Yes | OCI image reference |
| `service_group.services` | Yes | Yes | List of service port mappings |
| `service_group.services[].port` | Yes | Yes | External port |
| `service_group.services[].destination_port` | No | Yes | Internal port (defaults to `port`) |
| `service_group.services[].handlers` | No | Yes | List of handlers (e.g. `["tls","http"]`) |
| `service_group.domains` | No | Yes | Custom domains to attach |
| `service_group.domains[].name` | Yes | Yes | Domain name |
| `service_group.domains[].certificate.name` | No | Yes | Name of a `ukc_certificate` resource |
| `args` | No | Yes | Command arguments |
| `memory_mb` | No | Yes | Memory in MiB (16–256, default 256) |
| `autostart` | No | Yes | Start the instance immediately after creation |

:::note
`env` has no input on the `ukc_instance` resource—the provider treats it as computed (read-only), even though the platform API supports it at creation time.
:::

#### Attribute reference (computed)

| Attribute | Description |
|---|---|
| `uuid` | Instance UUID |
| `name` | Autogenerated instance name |
| `fqdn` | Public FQDN |
| `private_fqdn` | Private FQDN for internal communication |
| `private_ip` | Private IP address |
| `state` | Current instance state |
| `created_at` | Creation timestamp |
| `boot_time_us` | Boot time in microseconds |
| `env` | Environment variables (read-only) |
| `network_interfaces[].uuid` | Network interface UUID |
| `network_interfaces[].name` | Network interface name |
| `network_interfaces[].private_ip` | Network interface IP |
| `network_interfaces[].mac` | `MAC` address |
| `service_group.uuid` | Service group UUID |
| `service_group.name` | Service group name |
| `service_group.domains[].fqdn` | Assigned FQDN for the domain |
| `service_group.domains[].certificate.uuid` | Certificate UUID |
| `service_group.domains[].certificate.state` | Certificate state |

#### Import

```bash title=""
terraform import ukc_instance.app <uuid>
```

### `ukc_volume`

Creates and manages a Unikraft Cloud volume.
Unlike instances, volumes support **in-place updates**: you can grow `size_mb` without destroying and recreating the resource.

#### Example

```terraform title="main.tf"
resource "ukc_volume" "data" {
  name    = "my-volume"
  size_mb = 512
}
```

#### Argument reference

| Argument | Required | Force-replace | Description |
|---|---|---|---|
| `size_mb` | Yes | No | Volume size in MiB; updatable in-place |
| `name` | No | Yes | Volume name; changing the name forces replacement |

#### Attribute reference (computed)

| Attribute | Description |
|---|---|
| `uuid` | Volume UUID |
| `state` | Current volume state |
| `persistent` | Whether the volume persists after detach |
| `created_at` | Creation timestamp |
| `attached_to[].uuid` | UUID of attached instance |
| `attached_to[].name` | Name of attached instance |

#### Import

```bash title=""
terraform import ukc_volume.data <uuid>
```

### `ukc_certificate`

Uploads a TLS certificate (chain + private key) to Unikraft Cloud.

#### Example

```terraform title="main.tf"
resource "ukc_certificate" "tls" {
  name  = "my-cert"
  cn    = "app.example.com"
  chain = file("cert-chain.pem")
  pkey  = file("private-key.pem")
}
```

#### Argument reference

| Argument | Required | Description |
|---|---|---|
| `cn` | Yes | Common name (domain) |
| `chain` | Yes | Certificate chain in `PEM` format |
| `pkey` | Yes (sensitive) | Private key in `PEM` format |
| `name` | No | Certificate name |

#### Attribute reference (computed)

| Attribute | Description |
|---|---|
| `uuid` | Certificate UUID |
| `status` | Operation status |
| `message` | Status message |
| `data.certificates[].common_name` | Parsed common name |
| `data.certificates[].state` | Certificate state |
| `data.certificates[].created_at` | Creation timestamp |

#### Import

```bash title=""
terraform import ukc_certificate.tls <uuid>
```

## Data sources

### `ukc_instance`

Reads a single instance by UUID.

```terraform title="main.tf"
data "ukc_instance" "app" {
  uuid = "dcaf899e-6831-4641-86a6-e2b39e9f0d98"
}
```

Returns all instance attributes including `env`, `args`, `network_interfaces`,
`service_group`, and `boot_time_us`.

---

### `ukc_instances`

Returns a list of instance UUIDs, with optional state filtering.

```terraform title="main.tf"
data "ukc_instances" "running" {
  states = ["running"]
}
```

| Argument | Description |
|---|---|
| `states` | Optional list of states to filter by: `stopped`, `starting`, `running`, `draining`, `stopping` |

:::note
The provider applies state filtering client-side after fetching all instances.
For large fleets this may be slow.
:::

Returns: `uuids`—list of matching instance UUIDs.

---

### `ukc_volume`

Reads a single volume by UUID.

```terraform title="main.tf"
data "ukc_volume" "data" {
  uuid = "7ab06383-ac03-4a81-968a-1b0cff03c23a"
}
```

Includes a `mounted_by` list (not available on the `ukc_volume` resource):

| Attribute | Description |
|---|---|
| `mounted_by[].uuid` | UUID of the mounting instance |
| `mounted_by[].name` | Name of the mounting instance |
| `mounted_by[].read_only` | True if the mount has read-only access |

---

### `ukc_volumes`

Returns a list of volume UUIDs, with optional state filtering.

```terraform title="main.tf"
data "ukc_volumes" "available" {
  states = ["available"]
}
```

| Argument | Description |
|---|---|
| `states` | Optional list of states: `uninitialized`, `initializing`, `available`, `idle`, `mounted`, `busy` |

:::note
The provider applies state filtering client-side after fetching all volumes.
:::

Returns: `uuids`—list of matching volume UUIDs.

## Known limitations

- **No `env` input on `ukc_instance`**: Terraform doesn't support environment variables at instance creation; use the API or CLI instead.
- **No service group resource**: service groups form implicitly via `ukc_instance`. No standalone `ukc_service_group` resource exists.
- **No autoscale resource**: manage autoscale configurations via the API or CLI.
- **No volume attach/detach**: Terraform doesn't attach volumes to instances. Use the API or CLI for attach/detach operations.
- **All instance changes force replacement**: the provider doesn't support partial updates for instances; any attribute change destroys and recreates the instance.
