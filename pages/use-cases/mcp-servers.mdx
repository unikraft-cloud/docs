Run MCP servers as microVMs that wake in milliseconds when an agent calls them, and cost nothing between calls.

<ValueCards>
  <ValueCard title="Start bulky tools in milliseconds" metric="wakes in < 10 ms">
    Tools with expensive initialisation (indexes, model loads, browsers) are [snapshotted](/features/snapshots) warm and resumed on the call.
  </ValueCard>
  <ValueCard title="Costs nothing between calls" metric="zero idle cost">
    Agent traffic is bursty and mostly idle.
    A server that isn't being called isn't running, and isn't billed.
  </ValueCard>
  <ValueCard title="Run as many as you need" metric="100K+ microVMs / server">
    One isolated server per agent, per tool or per tenant, rather than one shared process handling everyone.
  </ValueCard>
</ValueCards>
