## Under the hood

The platform features this use case is built on.

<FeatureTable>
  <FeatureRow title="Branching" href="/features/branching">
    Clones a running database instance, including memory and volume state, with at most a few milliseconds of downtime on the original.
  </FeatureRow>
  <FeatureRow title="Checkpoints" href="/features/checkpoints">
    Capture the full state of an instance and keep a history, so you can restore from a known good snapshot.
  </FeatureRow>
  <FeatureRow title="Stateful scale-to-zero" href="/features/scale-to-zero#stateful-scale-to-zero">
    Snapshots memory and volume state when the database is idle and restores it in milliseconds on the next request.
    Pay only for what you use.
  </FeatureRow>
  <FeatureRow title="Private VM-VM communication" href="/platform/networking#internal-communication">
    The database can be hidden from the public internet entirely, reachable only by your web server.
  </FeatureRow>
</FeatureTable>
