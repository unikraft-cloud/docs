Run full developer environments that [scale to zero](/features/scale-to-zero#stateful-scale-to-zero) when idle and start back up exactly as you left them, in milliseconds.

<ValueCards>
  <ValueCard title="Resumes in milliseconds, as you left it" metric="resume in < 10 ms">
    Memory and disk are [snapshotted](/features/snapshots) when the developer stops typing, and restored on the next keystroke, processes still running.
  </ValueCard>
  <ValueCard title="A workspace that outlives the instance" metric="persistent volumes">
    The workspace state is held in persistent [volumes](/platform/volumes), so [scale-to-zero](/features/scale-to-zero#stateful-scale-to-zero) cycles and restarts don't lose work.
  </ValueCard>
  <ValueCard title="Run as many as you need" metric="100K+ microVMs / server">
    One environment per developer, per branch or per review, with idle ones costing nothing.
  </ValueCard>
</ValueCards>
