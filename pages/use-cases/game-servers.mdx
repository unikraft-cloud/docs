Start heavy gaming workloads in milliseconds, and [scale them to zero](/features/scale-to-zero#stateful-scale-to-zero) when the session is empty.

<ValueCards>
  <ValueCard title="Empty session, no server" metric="restart in < 10 ms">
    Shut the server down when the last player leaves and bring it back in milliseconds when someone joins.
  </ValueCard>
  <ValueCard title="Inject configuration with ease" metric="change config without rebuilding image">
    Per-world config and mods are mounted onto the instance rather than baked into a new image each time.
  </ValueCard>
  <ValueCard title="Run as many as you like" metric="100K+ microVMs / server">
    One instance per world or match, isolated as a VM; the platform is built for that scale.
  </ValueCard>
</ValueCards>
