Deploy hardware-isolated serverless functions that boot and respond in milliseconds, and cost nothing between calls.

<ValueCards>
  <ValueCard title="Real VM isolation, not containers or isolates" metric="own kernel per function">
    Most serverless platforms share a kernel or a language runtime between tenants.
    Every function here is a hardware-isolated microVM with its own kernel, safe enough to run code you didn't write.
  </ValueCard>
  <ValueCard title="Start bulky runtimes in milliseconds" metric="cold start < 10 ms">
    Bring your own runtime, however heavy.
    Snapshot it warm into a [template](/platform/instances#instance-templates): no warm pool to keep paying for.
  </ValueCard>
  <ValueCard title="Fast to start and still customizable" metric="templates + ROMs, no rebuild">
    Templates alone would give you identical runtimes.
    The function's own code arrives as a [ROM](/features/roms) mounted at boot, so one warm template serves many different functions, and shipping a new one is a few KB, not an image build.
  </ValueCard>
</ValueCards>
