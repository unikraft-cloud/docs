Securely run untrusted sandboxes in milliseconds; [scale them to zero](/features/scale-to-zero#stateful-scale-to-zero), [branch](/features/branching) or [checkpoint](/features/checkpoints) them as needed.

<ValueCards>
  <ValueCard title="Start heavy sandboxes in milliseconds" metric="cold start & scale-to-zero < 10 ms">
    Snapshot a fully initialised environment (runtime, deps, warm caches) into a [template](/platform/instances#instance-templates) and boot each sandbox from it.
    Idle ones cost nothing. [Scale to zero](/features/scale-to-zero#stateful-scale-to-zero) and restore statefully in ms.
  </ValueCard>
  <ValueCard title="Genuinely secure sandboxes" metric="own kernel · secrets never enter the sandbox">
    Every sandbox is a hardware-isolated microVM with its own kernel, not a container sharing the host's.
    Its traffic leaves through a [shield](/features/network-shield) microVM that filters egress and holds your credentials, so untrusted code can use an API without ever seeing the key.
  </ValueCard>
  <ValueCard title="Branch, checkpoint, run as many as you need" metric="branch & restore in < 10 ms · platform is built for scale">
    One hardware-isolated microVM per task: [branch](/features/branching) a live sandbox to launch sub-agents from its exact state, or [checkpoint](/features/checkpoints) it and rewind when a path goes wrong.
  </ValueCard>
</ValueCards>

## Under the hood

The platform features this use case is built on.

<FeatureTable>
  <FeatureRow title="Network shield" href="/features/network-shield">
    A separate microVM that all network traffic is routed through.
    It can filter traffic and inject secrets.
  </FeatureRow>
  <FeatureRow title="Plugin API" href="/features/plugins">
    An authenticated channel over which command execution and filesystem access services are provided.
  </FeatureRow>
  <FeatureRow title="Branching" href="/features/branching">
    Clones a running sandbox, memory and volume state included, in milliseconds, so a sub-agent can start from the parent's exact state instead of setting itself up again.
  </FeatureRow>
  <FeatureRow title="Checkpoints" href="/features/checkpoints">
    Capture the full state of a sandbox and keep a history, so you can rewind to the last good point when a run goes wrong.
  </FeatureRow>
  <FeatureRow title="Autokill" href="/features/autokill">
    Optionally terminates long-running sandboxes so a stuck or hostile workload can't run indefinitely.
  </FeatureRow>
  <FeatureRow
    links={[
      { label: "Stateful scale-to-zero", href: "/features/scale-to-zero#stateful-scale-to-zero" },
      { label: "templates", href: "/platform/instances#instance-templates" },
    ]}
  >
    Give large, heavy sandbox environments millisecond startup, and cost nothing while idle.
  </FeatureRow>
</FeatureTable>
